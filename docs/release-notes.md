# 下100层 v1.0.0-rc.6

完整Classic网页游戏：六种平台、单向连续碰撞、确定性生成、100层后无尽、暂停重开、中文响应式UI、手机触控、本机Top 10、设置、原创SVG与合成音频。

根据用户截图反馈放大桌面中央游戏区：1920×1080下宽620px，1280×720下约413px，按窗口高度适配，并收紧外围留白。场地仍为3:4，物理尺寸360×480，玩法不因显示尺寸改变。

修复场地中间尖刺平台边缘的错误死亡：人物横向离开时，扫掠碰撞曾使用移动前的位置再次命中旧平台，导致重复落地并扣血。现在离开的平台不会参与当步落地检测，每块尖刺本局最多实际伤害一次，离开再回来也不重复扣血。此前平台中间往返测试漏掉了边缘，此次补齐左右边缘、再次落地及浏览器血条/结算回归，见docs/bug-spike-edge.md。

保留每个平台1层、横移170 px/s、初速140和每5层加速。详见docs/difficulty-research.md。

自动化：44项规则/存档/长期模拟测试通过；五种浏览器项目完整60个用例中56通过、4按设计跳过，包含左右尖刺边缘的HP保持5点与结算隐藏检查。生产子路径加载、资源和测试入口剥离检查通过。完整记录见docs/test-report.md与docs/qa。

GitHub Actions完整验证后部署Pages。真实10分钟浏览器自动键盘测试是rc.1记录；rc.6通过模拟长期回归，没有将旧测试标为新版本实测。

这是发布候选版本。人工0—100层后继续、Android Chrome实机和难度复试玩验收尚待确认，因此没有宣称正式v1.0验收完成。
