# Classic行为规范

所有数值见src/core/profile.js，单位为秒和逻辑像素。场地360×480，六种平台宽100、厚12、间距60。起始玩家位于居中安全平台上方，重力自然落地。

方向键或A/D左右移动，双向同时按归零；传送带推力仍生效。无主动跳跃。角色站立随平台上升；顶部触及12px危险区扣5、解除附着；玩家顶边超过480即完全出屏死亡；HP归零死亡。

非尖刺落地+1；尖刺−4；HP范围0—10。受伤1秒保护不阻止底部死亡。假平台第一次落地触发，300ms警示、600ms失效，不被离开/再次落地重置；视觉不影响盒子。弹簧200ms发射−500，提前离开取消。传送带附着时±100附加速度，离开立即消失。

起始序号0；新平台递增。最深序号除5向下取整为层数；每10层基础滚速提高10%，100层提示仅一次，继续无尽。层数不回退；无独立积分。

平台位置尝试20次，可达区间以离开时相对平台垂直初速度0、t=sqrt(2*gap/gravity)、操作可横移moveSpeed*t为基础；从上一平台中心出发，目标盒子有效重叠额外允许(platformWidth+playerSize)/2−1px。该检查不证明任意玩家状态都可达，不保证无伤路径。候选失败夹到可达区间，不重新抽平台类型。

碰撞比较两对象前后脚底/顶面相对位置，求穿越时刻，再求当时横向重叠；最早碰撞优先，纯边缘不落地。从下方上穿没有碰撞。平台时间只由固定物理步推进。
