# v1.0需求基线

用途：课程答辩成品及公开在线试玩。Classic先行，电脑键盘优先、手机触控兼容。原创极简卡通微霓虹美术。

必做：六种平台、单向碰撞、左右移动、生命/顶部伤害/底部死亡、参考层数换算、100层后无尽、暂停重开、本机Top 10、设置、原创音画、测试、文档、Git历史、GitHub Pages。

不做：Modern、道具、全球榜、账号、后端、续关、安装包。页面1280×720仅为桌面设计基准，物理区域固定360×480。

完成门槛：自动化测试与构建通过，关键流程和正式素材齐全，无阻断/高优先级缺陷，公开部署可访问。人工0—100层与Android实机测试单独记录，自动化不得冒充人工验收。

每阶段保留小提交：基线→核心→流程→音画→QA材料→发布。未达到门槛不添加下一阶段功能。
