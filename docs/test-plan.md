# 测试计划

执行：npm test、npm run build、npx playwright install chromium firefox、npm run test:e2e。Windows另验Chrome/Edge；CI只运行Chromium/Firefox/手机模拟。

规则：HP、保护时间、六种平台状态、离开行为、单向连续碰撞、边缘、最早接触、相对运动、100层跨越、层数单调、速度增长、暂停、重开和死亡一次性。相同固定输入以30/60/120渲染步推进比较结果。固定种子2000链验证坐标/可达范围，20000样本验证类型概率。

存档：损坏/未知版本、字段验证、同分排序、Top 10、防重复、Unicode昵称16字符、内存降级、无进行中游戏存档。浏览器额外验证昵称纯文本，禁止存储不会崩溃。

浏览器：菜单/开始/暂停/恢复/重开、设置保存、结算与记录、失焦清输入、窗口变化3:4及无横向溢出、手机触控取消；正式SVG加载、音频首次交互、关闭特效规则不变、多次重开监听数量稳定。

工具：tools/verify-build.mjs在/ns-shaft-web-remake/仿生产路径执行加载/开始/暂停/刷新/资源错误检查，并确认DEV钩子不存在。tools/qa-soak.mjs 600运行真实10分钟浏览器键盘控制与重开，记录FPS、DOM、监听、平台、粒子、音频节点和堆内存；自动控制不是人工通关。tests/soak.test.js另运行10分钟模拟时间规则检查。

人工待办：人类玩家实际0—100层后继续；Android Chrome实机触屏/音频/旋转/后台切换；最终音效听感、色盲辨识、操作手感。未执行写待验，不以模拟器或事件注入替代。

发布门槛：规则、浏览器与生产烟测全部通过；阻断/高优先级缺陷为零；来源清晰。正式v1.0仍需人工清单完成，未完成时发布候选版本。
