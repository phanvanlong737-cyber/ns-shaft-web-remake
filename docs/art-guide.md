# 美术与音画规范

原创极简卡通微霓虹。深蓝低对比背景、薄荷色角色；六种平台分别为绿#65f080（普通）、红#ff3b5c（三角尖刺）、蓝#39baff（左箭头传送）、紫#e56dff（右箭头传送）、橙#ff9440（白色裂纹易碎）、黄#ffe45c（线圈弹簧）。填充与实色轮廓提高辨识度，左右传送带颜色分开。功能同时由形状表达，不只依赖红绿颜色。顶部尖刺使用明亮红色，明确即时死亡危险。

public/assets中的9个SVG同时是可编辑美术源文件和运行时文件；使用tools/generate-assets.mjs可完全复现。玩家源26×32（头部伸出盒子上方6px），逻辑碰撞盒26×26；平台源100×24（尖刺/标志有上方装饰），逻辑盒100×12。Logo48×48，背景360×480。运行时没有网络字体或第三方图片。

玩家：SVG为一致的角色底稿，Canvas实现待机轻呼吸、行走摆动、上升拉伸、下落倾斜、受伤闪烁、死亡旋转淡出；无需帧图，不修改逻辑位置与盒子。平台：传送带光点流动、假平台裂纹警示与失效碎片、弹簧压缩/释放视觉缩放。治疗、受伤、落地、100层粒子总上限180。减少动画关闭运动形变与粒子，保护期仍保留静态亮度提示。

响应式保持3:4实际场地；DPR渲染上限2，物理场地360×480。桌面按窗口高度放大，1920×1080下游戏列宽620px、Canvas618×824；1280×720下游戏列约412.5px、Canvas410.5×547.3，完整显示。手机触控栏位于画面外，不覆盖底部平台。窄横屏沿用可滚动布局。

音乐为16步原创五声音阶风格合成动机，0.4秒/步；正弦/三角波，无采样音源。音效包括点击、落地、伤害、治疗、弹簧、裂纹、碎裂、死亡、纪录和100层完成。音频仅在用户操作后启用，可调三路音量和静音；暂停即停止。
