# Classic行为规范

所有数值见src/core/profile.js，单位为秒和逻辑像素。场地360×480，六种平台宽100、厚12、间距60。起始玩家位于居中安全平台上方，重力自然落地。

方向键或A/D左右移动，双向同时按归零；传送带推力仍生效。无主动跳跃。角色站立随平台上升；顶边触及12px顶部尖刺危险区立即死亡，无视HP和受伤保护，解除附着且只结算一次；玩家顶边超过480即完全出屏死亡；HP归零死亡。

非尖刺落地+1；尖刺平台只在进入平台的落地事件扣5点，站立超过保护期仍不持续扣血；离开后重新落地属于新一次接触，遵守1秒受伤保护。HP范围0—10。受伤保护不阻止顶部尖刺或底部死亡。易碎平台第一次落地触发，150ms警示、300ms失效，不被离开/再次落地重置；视觉不影响盒子。弹簧200ms发射−500，提前离开取消。传送带附着时±100附加速度，离开立即消失。

起始安全平台为0层；后续每个平台计1层。落地后以最深平台序号为层数；跳过平台可跨层，重复落地不重复加层，回到浅层不回退。滚屏初速140 px/s，每5层增加初速的10%（14 px/s），100层为420 px/s。100层提示仅一次，继续无尽及加速；无独立积分。

平台位置尝试20次，可达区间以离开时相对平台垂直初速度0、t=sqrt(2*gap/gravity)、操作可横移moveSpeed*t为基础；允许从上一平台的有效站立边缘出发，两个平台都允许脚底有效重叠，额外允许platformWidth+playerSize−1px。该检查不证明任意玩家状态都可达，不保证无伤路径。候选失败夹到可达区间，不重新抽平台类型。

碰撞比较两对象前后脚底/顶面相对位置，求穿越时刻，再求当时横向重叠；最早碰撞优先，纯边缘不落地。从下方上穿没有碰撞。平台时间只由固定物理步推进。

暂停停止所有规则计时，失焦清输入并暂停。重开创建新的玩家、生成器、平台和本局事件；只保留设置与历史。

用户试玩后对齐4399实际SWF的类型比例：普通28%、尖刺19%、假17%、左右传送各9%、弹簧18%。横移第一轮由200校准到110，第二轮根据灵活度反馈改为170 px/s，同时提高滚屏初速及加速频率。原版来源、调参记录及保留差异见difficulty-research.md。
