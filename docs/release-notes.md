# 下100层 v1.0.0-rc.4

完整Classic网页游戏：六种平台、单向连续碰撞、确定性生成、100层后无尽、暂停重开、中文响应式UI、手机触控、本机Top 10、设置、原创SVG与合成音频。

根据最新实测要求，六种平台改为绿/红/蓝/紫/橙/黄，增强填充、轮廓与图例对比；左右传送带单独配色，保留箭头和其他形状区分。素材URL加入配色修订参数，避免沿用旧缓存。

易碎平台150ms警示、300ms破碎，停留时间减半。顶部尖刺触碰即死亡，无视受伤保护，显示对应死亡原因。尖刺平台保持仅落地扣5HP，站立不会持续扣血，并新增保护期结束后站立回归。

保留每个平台1层、横移170 px/s、初速140和每5层加速。详见docs/difficulty-research.md。

自动化：40项规则/存档/长期模拟测试通过，46项Windows桌面及手机模拟浏览器用例通过；生产子路径加载、资源和测试入口剥离检查通过。完整记录见docs/test-report.md与docs/qa。

GitHub Actions验证后部署Pages。真实10分钟浏览器自动键盘测试是rc.1记录；rc.4通过模拟长期回归，没有将旧测试标为新版本实测。

这是发布候选版本。人工0—100层后继续、Android Chrome实机和难度复试玩验收尚待确认，因此没有宣称正式v1.0验收完成。
