# 下100层 v1.0.0-rc.3

完整Classic网页游戏：六种平台、单向连续碰撞、确定性生成、100层后无尽、暂停重开、中文响应式UI、手机触控、本机Top 10、设置、原创SVG与合成音频。

根据用户明确要求，每个平台计1层，初始安全平台为0层，落地后显示最深平台序号。平台编号、HUD、结算、排行榜和100层事件使用同一成绩口径。跳过平台可跨层，重复落地不重复加层，回到浅层不回退。

保留横移170 px/s、初速140及每5层增加14 px/s。100层现在对应第100个平台，加速也随新层数更早出现。详见docs/difficulty-research.md。

自动化：36项规则/存档/长期模拟测试通过，46项Windows桌面及手机模拟浏览器用例通过；生产子路径加载、资源和测试入口剥离检查通过。完整记录见docs/test-report.md与docs/qa。

GitHub Actions验证后部署Pages。真实10分钟浏览器自动键盘测试是rc.1记录；rc.3通过模拟长期回归，没有将旧测试标为新版本实测。

这是发布候选版本。人工0—100层后继续、Android Chrome实机和难度复试玩验收尚待确认，因此没有宣称正式v1.0验收完成。

项目非4399官方；运行时美术与声音原创，来源与许可见docs/THIRD_PARTY_NOTICES.md。
